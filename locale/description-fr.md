# UCP2-Legacy: Patched AI Behaviour

Le comportement d’IA corrigé résout les principaux bugs de gestion économique. Il corrige aussi les troupes de départ pour éviter que les IA manquent de défenseurs à distance dans le mode « Croisé ». En dehors de ces améliorations, leur comportement reste largement celui du jeu d’origine.

Remplace tous les profils de comportement des IA d’origine dans leur ordre respectif.
